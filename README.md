Campusly — Campus Events & Clubs Portal

A student-friendly web application that helps students discover campus events, explore student clubs, and connect with campus activities.

Features

- Discover upcoming campus events
- Browse student clubs and communities
- Search events by name, club, venue, or category
- Filter events by Workshop, Tech, Culture, and Wellness
- Mark interest in events
- Join student clubs
- Responsive dashboard for desktop and mobile

Technologies Used

- React.js
- JavaScript
- HTML5
- CSS3
- Vite

Installation & Setup

1. Clone this repository:
   
   git clone YOUR_REPOSITORY_LINK

2. Open the project folder:
   
   cd campus-events-clubs-portal

3. Install dependencies:
   
   npm install

4. Start the development server:
   
   npm run dev

5. Open the local URL shown in your terminal.
